# Sistema de Cadastro de Alunos

Sistema web desenvolvido para realizar o cadastro
e visualização de alunos.

## Objetivo

O projeto foi desenvolvido como atividade prática
da disciplina Material Design Framework.

O objetivo é aplicar conceitos de:

- Git;
- GitHub;
- HTML5;
- CSS3;
- JavaScript;
- Clean Code;
- Trabalho colaborativo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Estrutura do Projeto

sistema-cadastro-alunos/
├── README.md
├── index.html
├── login.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── img/

## Como executar

1. Faça o clone do projeto.
2. Entre na pasta.
3. Abra o arquivo index.html.
4. Execute utilizando um navegador.

## Funcionalidades

- Cadastro de alunos;
- Exibição dos alunos cadastrados;
- Validação básica dos campos;
- Seleção de curso;
- Página de login;
- Interface responsiva.

## Branches

### main
Branch principal do projeto.

### login
Branch destinada ao desenvolvimento das funcionalidades de login.

### cadastro
Branch destinada ao desenvolvimento das funcionalidades de cadastro.
